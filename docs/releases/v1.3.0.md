### New providers
- **OpenRouter** — paste your API key in *Settings → API keys*. Shows the key's spending limit, prepaid credits and balance, today / this week / this month spend, and the **daily free-model request quota** (50 or 1000 a day).
- **GitHub Copilot** — a GitHub token in *Settings → API keys* (or a signed-in GitHub CLI). Shows the monthly premium-request quota and its reset.
- **Gemini CLI** — uses the CLI's existing Google sign-in (read-only). Daily quota per model tier: Pro, Flash, Flash Lite.
- **Cursor** — uses the Cursor app's existing sign-in (read-only). Included usage for the billing cycle, Auto / API model shares and on-demand spend.

API keys are stored encrypted with Windows DPAPI for your user account and are sent only to their own service. A provider's card appears as soon as it is set up — no restart needed.

### Fixes
- **Start with Windows** now also adds Kota to Windows' *Startup apps* list. Current Windows 11 builds only start an app at sign-in when it is listed there, so Kota often didn't start. Existing installs are fixed automatically on the next launch; if you turned Kota off in Windows' Startup apps, that choice is kept.
- The white Codex logo stays visible on the light taskbar and panel.

### Install / update
Download **Kota-win64.zip**, extract it and run **Kota.exe** (or download Kota.exe directly). If Kota is already installed, choose *Yes* to update — your settings are kept. Kota 1.2.0 shows a "new version" link in its panel within a day.

Windows SmartScreen may warn because the exe isn't code-signed: *More info → Run anyway*.
